## 4. Selected candidate — bounded design accepted, execution not authorized

Qualify the accepted modern-only adapter over **real Node HTTP + Vona executor/ALS/handleRequest/raw router**, with synthetic request-scoped JSON/SSE and lifetime fixtures. Do not register a production controller, add another app, or implement business dispatch. This provides integration value beyond an empty adapter while leaving the full production chain unqualified.

### Concrete composition

1. Use one dedicated root-managed single-file invocation and the existing Vona singleton app. No proven per-test fully started app factory exists; another `VonaApplication` changes the global app resource pointer.
2. Command-local `SERVER_LISTEN_DISABLE=true`; require effective disablement, test/managed identity, **no `app.server`**, and no pre-existing target routes. Fail rather than modifying config or taking over a busy resource.
3. Serial suite owns dynamic raw POST/GET/DELETE `//mcp` registrations and a test-owned `127.0.0.1:0` listener. Derive exact local Host/Origin from its allocated address; enforce ADR 0004's direct-only admission **before executor**, plus private request-object membership checked by handlers.
4. Explicit `instanceName: null`, literal `innerAccess: false`, native `req/res`, no inherited Passport/state or transaction; no per-request database switch. Invoke real Koa `handleRequest` and `SymbolRouterMiddleware`, not the full `app.middleware` chain. No tenant/business beans or `performAction` calls.
5. Install the per-request pure Node native writer/error boundary before `handleRequest`; contain rejection of the whole executor promise. Use one bounded body reader and the selected adapter's verified pre-parsed-body path. Await adapter, owned tasks and transport cleanup, then executor/disposal, before exactly-once capacity release.
6. In `finally`, close admission, drain/cancel and await owned work, close owned sockets/listener/timers, unregister only owned routes. Managed runner owns app/resource shutdown. Uncooperative work fails the run; it does not become detached successful cancellation.

The direct-only policy rejects forwarding, credentials, selectors, query/alternate targets, method overrides and ambiguous framing. Invalid present Origin stays `403`; explicit GET/DELETE are `405`. Exact accepted fixture status/precedence belongs to ADR 0004. Null is a test-only no-instance branch, not production tenant admission or an authorized default instance.

### Source-backed feasibility and proof limits

- [Router register/unRegister](../../vona/src/suite-vendor/a-vona/modules/a-web/src/bean/bean.router.ts) and [web main](../../vona/src/suite-vendor/a-vona/modules/a-web/src/main.ts) share the per-app router. Raw registration bypasses controller ContextRoute/guards/interceptors/pipes/Aspect. It can exercise path-helper/raw lookup, **not** decorated controller registration or parser/envelope override correctness.
- [Executor](../../vona/src/suite-vendor/a-vona/modules/a-executor/src/bean/bean.executor.ts) resolves instance before the `handleRequest` callback; middleware-first admission is too late. Null skips instance lookup, but is incompatible with the ordinary instance middleware; the reduced chain is intentional.
- [Production listen startup](../../vona/src/suite-vendor/a-vona/modules/a-web/src/bean/startup.listen.ts) and [ALS](../../vona/packages-vona/vona-core/src/lib/core/asyncLocalStorage.ts) expose genuine native/context/disposal anchors. Default listener has no whole-executor outer catch; a disposer failure can skip subsequent disposal and counter decrement. The harness contains rejection, not repairs those framework gaps.
- [Managed runner](../../scripts/runIsolatedTest.ts) inherits the listener-disable flag and forwards the selector; [test CLI](../../vona/packages-cli/cli-set-api/src/lib/bean/cli.bin.test.ts) accepts `src/...`. [Test bootstrap](../../vona/packages-cli/cli-set-api/toolsIsolate/test.ts) starts the singleton and appends the standard runner completion file. Thus “single-file” means one selected module test plus runner infrastructure, not a second app or no app startup.

No full system middleware, production controller, Host/instance/OAuth admission, ordinary-route regression, domain cancellation/rollback, deployment quota or protected-audit guarantee is proved by this candidate. The accepted production route and full ATP retain all of those applicable obligations.
