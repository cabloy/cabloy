## Seven bounded proof conditions

1. **Pre-executor admission:** denied/missing/ambiguous/unavailable binding and provider exception assert zero executor calls, reservation before provider, fixed empty outcome and exactly one response end. Undefined binding/limits cannot open executor admission.
2. **Trusted options:** controlled and real adapters assert exact keys, explicit deliberate default instance `''`, `innerAccess: false`, `dbInfo: { level: 0 }`, native pair and no caller spread/Passport/extraData. Real setup uses separate `mockCtx(...)` boundaries and a read-only check of the existing managed seeded instance, with no test-owned persistence.
3. **Real healthy ownership:** two independent real `newCtx(...)` operations enter distinct contexts and held work; third admission is 429 without provider invocation. Disconnect does not free either slot. Work release permits normal nonthrowing scoped-disposer witnesses to enter another held barrier; both slots remain occupied until disposal and entire `newCtx` fulfill. Final snapshot is healthy/open, active 0, reservations 2, releases 2. The disposer witness uses the existing container instance-table fixture seam, not a new public lifecycle API.
4. **Controlled faults only:** before-callback, during-held-callback, post-callback commit-stage and disposal-stage rejections enter explicitly distinct counters/branches. During-callback rejection does not settle held work or cleanup; its finally-owned release permits completion. All four report fixed failure, retain reservation, close admission and make no normal-disposal claim. No real commit/disposer failure is installed or repaired, and no framework counter is altered.
5. **Failure gate:** precommit failures write one empty response. Committed synthetic response retains status 200, gets no appended body/end and is destroyed without an Error argument. A late pure error callback after completion performs no further write/destroy; the event's failure classification 500 is not a rewritten committed wire status.
6. **Cancellation is not settlement:** cleanup failure/one-second overrun and five-second held-provider deadline remain unhealthy with reservation retained. The provider receives abort, but the returned task stays pending and executor count remains zero until the test releases its owned barrier in finally. Held tasks are released; conservative active counts on faulted synthetic owners are accounting retention, not leaked real Vona scopes. Owner `close()` closes admission/signals cancellation; it is not app shutdown or forced task settlement.
7. **Inert scope:** source/import and unchanged module-index checks show no route/bean/startup/AOP/SDK/listener registration. Existing native fixture and application settings remain unchanged. This is inert-import/source-scope evidence, not standard-startup interception, ordinary-route regression or native socket/backpressure proof.
