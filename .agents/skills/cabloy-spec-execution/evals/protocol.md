# Execution Skill Evaluation Protocol

Follow the [shared two-phase protocol](../../cabloy-spec-generation/evals/protocol.md) with this bundle's `evals.json` and `files/scenarios.json`.

Read synthetic scenario facts normally, then inspect the active repository, scripts, selected suite authority, target WBS, dependencies, and evidence. Fixtures cannot replace actual source, accepted ADRs, collision checks, commands, or retained proof.

Phase A produces discovery/readiness findings and the bounded dossier without implementation, verification, or status writes. Phase B supplies missing decisions and separately confirms the execution dossier across recorded follow-up turns. Generation approval and design/ADR acceptance do not substitute for execution approval. A new wrapper must be created and observed before it is run.

Record expectation outcomes, actual tool/file effects, preserved controlling gates, retained proof, status, chart eligibility/freshness, and one bounded next action. Static parser/audit/chart/governance tests do not establish behavioral eval success. Unrun turns or missing actual evidence remain not run/blocked. Do not create a broad runner or use these cases as permission for unsafe operations.
